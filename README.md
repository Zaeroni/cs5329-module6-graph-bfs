# Programming Assignment 6: Graph Representation and BFS Traversal

Name: Alzarius Boykins

## Description
A Python program that represents an undirected graph with an adjacency list
and runs Breadth-First Search (BFS) using a queue. It prints the order in
which vertices are visited.

## How to run
python3 graph_bfs.py

## Files
- graph_bfs.py: Graph class, BFS method, and test cases
- README.md: this file
- report.md: written report

## Test graphs
1. Connected graph (5 vertices), BFS from A and from E
2. Disconnected graph (two components: A-B-C and D-E), BFS from A and from D
3. Six-vertex graph with a cycle, BFS from A and from F
